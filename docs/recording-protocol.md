# 실험 촬영 프로토콜

임계값 조정과 SVM/RF 비교에 쓸 영상을 찍는 방법입니다. 진행자 1명과 피험자 1명이 함께 해요.

## 준비

- **동의:** 촬영 전에 영상 녹화와 데이터 활용 동의를 받아요. 영상은 팀 PC의 `ai/data/videos/`에만 두고(git에 올라가지 않음), 프로젝트가 끝나면 삭제해요.
- **기기:** 앱 검증 기기와 같은 폰이 가장 좋아요. 세로로 거치하고 1080p 이상, 30fps로 찍어요.
- **보관:** 영상은 OneDrive·구글 드라이브처럼 자동으로 올라가는 폴더 말고 PC 로컬 폴더(예: `C:\posture-data\videos`)에 둬요. 명령마다 `--data C:\posture-data`를 붙이면 돼요.
- **배치:**
  - 피험자 옆 **90°**, 거리 **1~1.5m**, 렌즈 높이는 **책상 높이**
  - 화면에 **귀·어깨·골반**이 다 들어오게 해요. 책상이 골반을 가리지 않게 의자를 조금 빼 주세요.
  - 피험자마다 **왼쪽, 오른쪽** 양쪽에서 찍어요(방향 통일 규칙 검증용).
  - 조명이 다른 장소 2곳 이상에서 찍으면 좋아요.
- **복장:** 머리카락이나 후드가 귀를 가리면 기록해 둬요(subjects.csv의 비고).

## 자세는 두 가지 (2026-11-18 팀 결정)

앱은 **바른 자세 / 거북목** 두 가지만 판정해요. 허리를 숙인 자세도 거북목이에요. 그래서 촬영도 두 자세면 돼요.

### 권장: 자세별로 나눠 찍기 (1인 영상 2개)

| 영상 | 하는 법 | 길이 |
|---|---|---|
| `S1_normal.mp4` | 바른 자세. 등을 기대지 않고 허리를 세우고, 귀가 어깨 위에 오게 | 1분 이상 |
| `S1_fhp.mp4` | 거북목. 평소 공부할 때처럼 머리를 내밀고 구부정하게(허리를 숙여도 돼요) | 1분 이상 |

- 두 영상은 **같은 자리, 같은 카메라 위치**에서 이어서 찍어요. 바른 자세 영상으로 그 사람 기준(캘리브레이션)을 잡고 거북목 영상에도 써요.
- 녹화를 켜고 **3초 가만히** 있다가 자세를 시작해요. 앞 3초와 마지막 1초는 분석에서 자동으로 빼요.
- 카메라는 **정확히 옆(90°)**. 등이 보이는 뒤쪽 비스듬한 각도면 골반을 잘못 잡아요.
- 모자는 벗어 주세요(귀를 가려요). 검은 옷에 검은 의자처럼 몸과 배경이 비슷하면 관절을 잘 못 잡아요.
- 라벨은 영상마다 한 줄이면 돼요.
  ```
  python -m posture_ai label-whole S1_normal --posture normal
  python -m posture_ai label-whole S1_fhp --posture fhp
  ```
- 이 방식은 자세가 **바뀌는 순간**이 없어서 반응 속도(지연)는 잴 수 없어요. 지연은 아래 150초 시나리오나 실기기 테스트에서 재요.

## (이전 방식) 데이터 수집 대본 (1인 4분)

처음 계획했던 방식이에요. 한 영상 안에서 자세를 바꿔 가며 찍어요. 지금은 위의 나눠 찍기를 권장해요.

네 자세 × 20초를 한 회차로 하고 **3회** 반복해요. 자세 사이에는 쉬지 않고 바로 이어 가요.

| 순서 | 자세 | 하는 법 |
|---|---|---|
| 1 | 바른 자세 (NORMAL) | 등을 기대지 않고 허리를 세우고, 귀가 어깨 위에 오게 |
| 2 | 전방머리 (FHP) | 상체는 그대로 두고 **머리만** 화면 쪽으로 쭉 내밀기 |
| 3 | 상체 기울임 (LEAN) | 머리–몸통을 한 줄로 유지한 채 **골반부터** 앞으로 숙이기 |
| 4 | 둘 다 (BOTH) | 상체를 숙이면서 머리도 내밀기 |

- 앱은 2·3·4번을 모두 거북목으로 판정해요.
- 진행자는 자세가 바뀔 때마다 "바른 자세", "머리", "숙이기", "둘 다"를 말해요.
- 녹화를 시작하면 대본 첫 자세 전에 **손뼉을 한 번** 쳐 주세요. 라벨 시작 시각을 맞출 때 써요.
- 대본대로 찍었다면 라벨은 시작 시각만 알면 자동으로 만들어져요.
  ```
  python -m posture_ai label-script S1_R_rep1to3 --start 4.2 --repeats 3
  ```
- 대본을 벗어났다면(실수, 재촬영) 키 입력 도구로 기록하거나 라벨 CSV를 직접 고쳐요.
  ```
  python -m posture_ai label-keys S1_R_rep1to3
  ```

## 앱 테스트용 150초 공통 시나리오

정상 20 → 전방머리 20 → 정상 15 → 상체 기울임 20 → 정상 15 → 둘 다 20 → **자리 비움 15** → 정상 25 (초)

라벨: `label-script <녹화> --script scenario150 --repeats 1 --start <초>`

## 파일 이름과 메타데이터

- 영상: `data/videos/<녹화이름>.mp4`. 예: `S1_R_rep1to3.mp4` (피험자_방향_회차)
- `data/subjects.csv`
  ```csv
  recording,subject,side,location,labeler,rotate
  S1_R_rep1to3,S1,right,lab,A,0
  S1_L_rep1to3,S1,left,lab,A,0
  ```
  - `subject`: 분할 기준이에요. 같은 사람은 같은 ID를 써요.
  - `rotate`: 영상이 옆으로 누워 있으면 90/180/270을 적어요. 폰으로 세로 촬영한 영상은 머리가 왼쪽으로 누워 보이는 경우가 많은데, 그때는 90이에요.

## 촬영 후 처리 순서

```
python -m posture_ai extract                  # 영상 → data/landmarks/*.csv (5fps)
python -m posture_ai visualize S1_R_rep1to3   # 스켈레톤·라벨을 겹친 영상으로 검수
python -m posture_ai analyze                  # 비교표·임계값·리포트 → outputs/real/
```
