# 정답 라벨링 가이드

정답은 **판정 규칙과 상관없이** 사람이 영상을 보고 정해요. 특징값이나 임계값을 보면서 라벨을 달면 평가가 의미 없어져요.

## 두 축을 따로 기록

| 축 | 1로 표시하는 경우 | 0으로 표시하는 경우 |
|---|---|---|
| `head_forward` | 몸통 선보다 **머리가 앞으로 나와** 귀가 어깨보다 확실히 앞에 있음 | 귀가 어깨 위나 그 근처에 있음 |
| `torso_lean` | 골반부터 **상체가 앞으로 숙여짐**(등받이·수직선에서 확실히 벗어남) | 상체가 서 있거나 뒤로 기댐 |

- 두 축은 **동시에 1**이 될 수 있어요(BOTH).
- 앱은 둘 중 하나라도 1이면 거북목(FHP)으로 판정해요(2026-11-18 팀 결정). 그래도 라벨은 두 축을 따로 달아요. 그래야 머리 기준(T₁)과 몸통 기준(T₂)을 각각 정하고, 어느 쪽을 놓치는지 알 수 있어요.
- 상체만 숙이고 머리는 몸통과 일직선이면 → `head_forward=0, torso_lean=1`
- 뒤로 기댄 자세는 기울임이 아니에요(`torso_lean=0`).
- 사람이 화면에서 벗어나면 `away=1` (두 축은 무시)

## 제외(`exclude=1`)

- 판단이 애매한 구간, 귀·어깨·골반이 가려진 구간, 피험자가 물을 마시는 등 대본에 없는 동작
- 자세가 바뀌는 지점 **±1초**는 따로 표시하지 않아도 분석 코드가 자동으로 빼요.

## 자세별로 나눠 찍은 영상

영상 전체가 한 자세라 `label-whole`로 한 줄만 만들면 돼요(앞 3초·뒤 1초는 자동으로 빼요).
```
python -m posture_ai label-whole S1_normal --posture normal
python -m posture_ai label-whole S1_fhp --posture fhp
```
- 거북목은 원인(머리/허리)을 나누지 않아요. 파일에는 `head_forward=1`로 기록되고, 분석은 "머리 또는 허리"(`fhp`)로 해요.
- 영상 중간에 자세가 풀렸거나 몸을 크게 움직인 구간이 있으면 그 구간을 `exclude=1`로 따로 나눠 주세요.

## 라벨 파일 형식 (`data/labels/<녹화>.csv`)

```csv
start_s,end_s,head_forward,torso_lean,away,exclude
0.000,4.200,0,0,0,1
4.200,24.200,0,0,0,0
24.200,44.200,1,0,0,0
```
구간이 겹치면 안 돼요(읽을 때 오류).

## 품질 확인 (Cohen's κ)

- 수집 전에 이 문서의 정의·예시·제외 기준을 팀이 함께 확정해요.
- 팀원 2명이 **같은 영상 일부**(전체의 20% 이상)를 각자 라벨링해요. 파일은 `labels_A/`, `labels_B/`처럼 따로 둬요.
- κ를 계산해요. 기준은 `fhp_kappa`(거북목/바른 자세)이고, head·lean은 참고용이에요.
  ```
  python -m posture_ai kappa labels_A/S1_R.csv labels_B/S1_R.csv
  ```
- κ가 **0.6 미만**(상당한 일치에 못 미침)인 속성은 불일치 사례를 같이 보고 정의를 고친 뒤 다시 라벨링해요.
- 최종 라벨은 합의한 버전 하나만 `data/labels/`에 둬요.
